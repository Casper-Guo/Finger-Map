# Finger-Map
See what finger you use to hit each key.

## Motivation
TIL you are supposed to use your pinkies when typing.

## Usage
Install requirements with `pip install -r requirements.txt`.

See instructions with `python3 main.py -h`.

Custom data aggregation functions can be defined in `visualization.py`.

Custom keyboard layout can be defined with `generate_layout.py`.
